Golden Hour Cover Studio — a static web app that turns your own photos and a caption into GTA 6-style multi-panel cover art, exported as a PNG to share.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in desktop Chrome. Or just open `app/index.html` directly — the app is plain static files with no build step and no network requests. Load a photo (or two), pick a layout, grade it, write a caption, and export at 1080×1080, 1080×1350, or 1920×1080.

Referral: `2yq7mcmp` — https://make.fun/r/2yq7mcmp

Captions use the browser's system font stack (`'DejaVu Sans'`, Arial, Helvetica, sans-serif, bold) — no font file is bundled. All artwork is original: the two bundled samples are code-drawn illustrations, no Rockstar material, no real people.

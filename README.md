Golden Hour Cover Studio — a web app that turns your own photo and a caption into striking multi-panel cover art with a sunset or neon colour grade, exported as a PNG in the post sizes 1080 x 1080, 1080 x 1350 and 1920 x 1080. Load a photo, crop and position it across the panels, pick a layout and a grade, write your caption, export. Everything runs offline in the browser; your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or serve `app/` with any static HTTP server and open `app/index.html`.
